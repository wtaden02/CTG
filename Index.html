Troubleshooting Steps

Press Esc or click outside to close

Check Power and Lights: Look closely at the small indicator light (LED) on the corner of the monitor.

  • Light completely off: Check the power cord at the monitor and wall outlet, and verify the physical power button is on.
  • Light amber or blinking: The monitor has power but no video signal. Make sure the computer is turned on and awake.
  • Re-seat the video cable: Unplug HDMI/DisplayPort from both ends, wait 5 seconds, and reconnect firmly. If a graphics card is installed, use its ports rather than the motherboard ports.
  • Wake the graphics driver: Press Windows + Ctrl + Shift + B. The screen may flicker and beep.
  • Test the monitor menu: If the built-in menu appears, the monitor works and the cable or computer should be checked. If no menu appears, the monitor may have failed.
If it still has a blank or black screen, call Customer Care by dialling 248.
  • Swap USB Ports: Connect the keyboard to a different USB port.
  • Refresh Power: Replace wireless batteries or toggle the physical power switch off and on.
  • Turn Off Filter Keys: Hold Right Shift for 8 seconds to disable accidental typing delays.
  • Reinstall Driver: In Device Manager, uninstall the keyboard component, then reconnect it.
If the keyboard is still not working, call Customer Care by dialling 248.
  • Swap USB Ports: Connect the mouse to a different working USB port.
  • Cycle the Power: Replace wireless batteries or toggle the power switch off and on.
  • Clean the Sensor: Remove dust, dirt, or hair from the optical sensor.
  • Reinstall Driver: Press Win + X, open Device Manager, uninstall the mouse, and reconnect it.
If the mouse is still not working, call Customer Care by dialling 248.
  • Check Physical Volume: Reconnect speakers or headphones and verify physical volume knobs.
  • Select the Output Device: Click the speaker icon in the taskbar and choose the correct playback device.
  • Unmute the System: Check the taskbar volume slider and ensure the master volume is not muted.
  • Update Audio Driver: Press Win + X, open Device Manager, right-click the primary audio driver, and select Update driver.
If there is still no sound, call Customer Care by dialling 248.

Isolate where the break is

When the internet drops, find out whether the failure is on this computer, the office network, or the ISP.

  • Local: Is it only this computer? Check the network cable or Wi-Fi, then try another device on the same connection.
  • LAN: Do other computers in the office also fail? If yes, check the switch, access point, or office router.
  • WAN: Does every device fail, including a wired connection at the router? The ISP link may be down.
  • Quick tests: Confirm the adapter is enabled, release and renew the IP address, then ping the gateway and 8.8.8.8.
If the issue remains, create a ticket to escalate the issue to Tier 2. A blank monitor is a separate problem — use Guide 01.
  1. Ask for the BITS sticker of the printer, the computer to be shared, and the source computer.
  2. Check Network on the source computer to verify visibility of the shared computer.
  3. Check whether the printer is already installed on the source system.
  4. If not installed, download and install the proper printer driver.
  5. Perform a test print to confirm functionality.
If it cannot print, create a ticket to escalate the issue to Tier 2.
  • Differentiate Wi-Fi vs. Ethernet: Test wired against wireless to rule out local RF interference or channel congestion.
  • Measure latency and jitter: Run ping -t [Gateway_IP] and ping -t 8.8.8.8 to see whether spikes are inside the building or on the ISP network.
  • Check local network usage: Use Task Manager on Windows or Activity Monitor on Mac to find processes consuming bandwidth.
  • Test DNS response time: Consider Cloudflare DNS 1.1.1.1 if pages take a long time to begin loading.
  • Power cycle hardware: Unplug the modem and router for 30 seconds, then reconnect.
If the connection is still slow, create a ticket to escalate the issue to Tier 2.
